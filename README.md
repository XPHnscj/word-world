# 雅思语境记忆

一个面向个人使用的、本地优先的雅思词汇学习工具。它把词表转换成短文，再通过原文填词、主动回忆和间隔复习，让“认识单词”逐步变成“能在新语境中调用”。

## 目前能做什么

- 内置 IELTS-4000 词库（`nglsh-master/IELTS-4000.txt`，4000+ 词条）：每天从未学词中随机抽取，并分散首字母，避免连续出现整组 a/b 开头词
- 词书架支持选择内置词书，并可新建自定义词书；词书、词卡、短文与复习记录保存在项目内的 SQLite 文件，换浏览器或清理站点缓存也不会丢失
- 粘贴或上传词表，自动去重并生成语境短文（TXT/CSV/Markdown 直接读取，Word/PDF 自动提取文字，图片由视觉模型 OCR）
- 使用 OpenAI、DeepSeek、通义千问或兼容接口；未配置 AI 时自动使用本地短文（本地回退时用词库英文释义兜底，词卡仍然可用）
- AI 生成时同时返回短文、中文翻译和逐词释义（词性 + 搭配），本地回退时使用内置模板
- 中文翻译与英文正文逐词对应：每个目标词返回 `translationZh`，且必须是同一篇翻译中的连续原文（自动校验；不匹配时自动按缺词定向重写，最多补两次）。旧版无逐词标注的短文会提示“重新生成”修复，不会用英文释义冒充中文或显示虚假划线
- 每篇短文标注一句值得模仿的“好句型”（蓝色高亮），AI 生成时给出句型结构与中文说明，本地模板自动挑选含目标词最多的长句
- 计划表所有天数开放，点开任意一天即显示该天专属短文（未生成时可一键从内置词库生成或去导入）
- 短文生成在后台进行：生成期间按钮显示“正在生成请稍后…”，完成后弹出通知条可一键查看，不会因重复点击生成多份
- 短文参考长度为 75–95 词、4–6 句，允许为自然表达略有浮动，明显超过 110 词才自动重写；内容从具体场景与感官细节切入，再自然推进到 IELTS 写作观点。目标词应分散在自然句子中，禁止连续逗号罗列，同一篇里每个目标词只出现一次
- 阅读页的“显示划线词 / 原文填词 / 检查原文填词 / 记录学习日”按钮固定在右下角，滚动页面时保持可见
- 在英文短文与中文翻译中对照目标词，查看语义和搭配
- 通过原文填词完成首次提取练习；已会的词可在填词时点击词后的中文提示标记跳过（单词显示为红色划线，原文中直接点击单词也可切换，再点可恢复，双向切换），之后不再出现在新短文里
- 按“重来 / 困难 / 记得 / 轻松”自评真实回忆表现，动态安排下次复习；任务按词卡表现轮转五种能力维度（识义/回忆/搭配/阅读/迁移）
- 复习时展示目标词在原文中的语境出处
- 将词卡、短文、复习记录、自定义词书与学习会话写入项目内 SQLite；IndexedDB 仅作为浏览器端的快速缓存与旧数据迁移来源
- 将学习数据、已掌握词、自定义词书与复习进度一起导出为 JSON

这是个人工具：没有账号系统、云同步、订阅或遥测。项目启动后会在 `data/learning.sqlite` 创建本地数据库；建议定期导出 JSON，或直接备份该 SQLite 文件。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器固定打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。启动器不会切换端口，以保证项目数据库与本地接口地址稳定。不配置模型也可以体验本地回退流程。双击 `launch.ps1` 会自动创建 `data` 目录并启动固定端口。

## 配置 AI

推荐复制 `.env.example` 为 `.env.local`，填写服务端环境变量（OpenAI 兼容协议，可指向
DeepSeek / 通义千问 / 其他网关）：

```bash
IELTS_AI_API_KEY=your_key
IELTS_AI_BASE_URL=https://api.deepseek.com
IELTS_AI_MODEL=deepseek-v4-flash
```

配置了 `IELTS_AI_*` 后，客户端填写的 Base URL / API Key 会被忽略，避免服务器密钥被转发到
任意地址。未配置 `IELTS_AI_*` 时，会回退读取 `OPENAI_API_KEY / OPENAI_BASE_URL /
OPENAI_MODEL`（兼容旧配置）；应用私有命名是为了防止机器上残留的 `OPENAI_*` 环境变量
意外覆盖本应用配置。

也可以在右上角“设置”中临时填写自己的 API Key。密钥只保留在当前浏览器标签的
`sessionStorage`，关闭标签后清除，并通过同源接口发送。

开发环境允许连接 `http://localhost` 上的兼容模型服务；生产环境中的个人自定义地址必须使用公开 HTTPS。

- 短文生成采用流式传输：AI 开始输出即可看到进度（首字约 1 秒），并对相同输入的重复生成做进程内缓存（30 分钟，命中约 24ms），避免重复等待
- 解析与打包均为微秒级（AI 回复解析 ~0.005ms、词卡打包 ~0.006ms、词库解析 ~2.4ms 且仅首次执行）

## 数据与隐私

- 学习数据的权威副本是项目目录下的 `data/learning.sqlite`，由本地 Node 服务通过同源接口读写；SQLite 使用事务保存整组数据，适合长期单机使用。
- 首次打开时，如果 SQLite 为空但浏览器 IndexedDB 里已有旧数据，应用会自动迁移一次；之后 IndexedDB 只作为缓存，清理浏览器站点数据后会从 SQLite 重新恢复。
- 设置和少量界面状态仍保存在 localStorage；API Key 仍只保存在当前标签页的 sessionStorage，不会写入 SQLite。
- 不依赖 MySQL、PostgreSQL、Docker 或账号服务，下载依赖后即可在本机使用。`better-sqlite3` 负责本地 SQLite 读写。
- 项目没有遥测或第三方分析脚本。
- AI 生成和图片 OCR 会把对应词表或图片发送给你配置的模型服务。
- “设置 → 导出学习数据”可以下载不含 API Key 的 JSON 备份。

## 项目结构

```text
src/app/page.tsx                          主界面与学习流程
src/app/api/ielts-vocab                    内置 IELTS 词库接口（读取 nglsh-master 词库）
src/app/api/context-packs/generate        语境短文生成接口（短文 + 翻译 + 逐词释义）
src/app/api/context-packs/extract         词表文件与图片提取接口（Word/PDF/图片 OCR）
src/app/api/storage                       项目数据库快照接口（GET/PUT）
src/lib/db.ts                             浏览器缓存、数据迁移与间隔调度
src/lib/serverStore.ts                    项目内 SQLite 持久化存储
src/lib/storageTypes.ts                   本地持久化快照类型
src/lib/ieltsVocab.ts                     词库解析器与客户端加载（可复用、可测试）
src/lib/contextPack.ts                    AI 回复的容错解析（JSON / 纯文本回退）
src/lib/provider.ts                       模型地址安全策略
```
